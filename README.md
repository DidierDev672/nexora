# Nexora

## Descripción

Nexora es una plataforma web para administrar alojamientos.

El sistema permite gestionar habitaciones, camas, huéspedes y reservas.

## Objetivo

Crear una plataforma sencilla para administrar espacios habitables.

## Módulos

- Habitaciones
- Camas
- Huéspedes
- Reservas
- Disponibilidad
- Ocupación
